# 财务工作台 · 单机 MVP

这是按你的学习网站视觉语言做的财务工作台离线销售版：浅青点阵背景、白色半透明面板、青蓝节点关系图、左侧工作区导航。销售包使用本地启动器打开页面，不需要联网。

## 已实现

- 财务总览：可用货币资金、应收未收、应付未付、银行净流入和现金趋势。
- 总览图表：30 天流入/流出双柱图、应收/应付到期压力分层条、经营性收款占比，直接突出资金缺口和收款质量。
- 数据可视化：收入分类、应收/应付账龄、资金流入/流出、预算执行、固定资产折旧、税费构成、发票查验状态、报表金额和结转控制均提供条形图、环形图或进度图，并保留数字与明细表作为核对依据。
- 银行收款：银行日记账分类，经营性收款与贷款、注资、内部转账、退款分开，支持人工覆盖。
- 银行对账：导入银行对账单，按业务单号优先、交易日+对方+金额后备匹配银行日记账，识别银行未达和账面未达账项，分别展示调节后余额并保留逐笔核实标记。
- 应收账款：销售单金额减已核销收款，展示部分收款、未收余额和账龄。
- 应付账款：采购单金额减已核销付款，展示部分付款、未付余额和到期排程。
- 工资管理：导入月度员工工资，按社保/公积金比例计算个人代扣、单位承担、实发工资和单位薪酬总成本；计提不冲现金，发薪日和社保公积金缴费日进入现金预测。
- 费用报销：导入员工费用单据，按业务真实性、票据合规、审批完整性和重复发票检查形成审核队列；已审批且票据通过的费用进入付款排程，按付款日期计入现金流出，并按预算科目跟踪执行率。
- 现金预测：日末余额按“日初可用资金 + 预计流入 - 预计流出”滚动计算，默认 90 天，可切换 30/60 天。
- 财务模块目录：补齐应收催收、资金管理、预算管理、固定资产、税务管理、发票管理、发票认证抵扣、发票查验、成本分摊、成本核算、期末结转、财务报表、财务分析和投资管理入口；这些页面直接由本地台账派生指标，结转和税务等需要正式会计规则的动作保留为草稿/人工复核状态。
- 产品成本核算：按月份维护产品产量、直接材料、直接人工、制造费用和标准单位成本，自动计算总成本、单位成本、差异率及状态；提供四项汇总、成本结构及实际/标准对比图，支持搜索、状态筛选、新增、编辑、删除、模板、导入和 Excel 导出。产品成本记录独立保存，并纳入本地备份；未结转的生产成本不自动计入利润表营业成本。
- 财务报表：财务报表页拆分为资产负债表、利润表、现金流量表三个 Tab；每个 Tab 都提供当前报表 PDF 打印导出和 Excel 导出，并提供“三表 Excel”工作簿导出。利润表按营业收入、营业成本及期间费用、净利润分组，显示本月数和本月占比，支持切换月份并保持页面与 Excel 口径一致。报表数据保留管理口径、期间、来源说明和资产/负债/权益勾稽差额。
- 用户入口：管理区仅保留数据备份和授权与设置；审计日志、只读系统信息、系统自检不在普通用户导航中展示，设置页也不再展示审计列表和自检按钮。
- 导入中心：银行、销售、采购、付款、工资、对账、费用、固定资产、发票和产品成本十个模板下载入口；支持 CSV/XLSX 全量预览、逐行字段与金额校验、按业务单号/流水号/资产编号/发票号码去重写入对应工作区，并记录成功/失败结果。
- 授权与设置：首次使用免费 7 天；到期后用户只需粘贴授权方发来的离线签名授权码，不需要设备 ID，用户端不能生成授权码。
- 数据安全：设置页提供本地 JSON 备份/恢复；关键操作仍在本机记录，业务数据和授权码在本机处理，不调用外部站点。
- 数据保存：演示数据、导入后的银行流水/银行对账单/销售单/采购单/付款单/工资明细/费用报销单、核实标记和导入记录写入浏览器 `localStorage`，刷新后保留。
- 附件功能分析：只借鉴业务信息架构、台账交互和自检/备份思路；附件中的外部 CDN、Service Worker、混淆授权、设备指纹和支付代码均未复制。详见 `docs/ATTACHMENT-AUDIT.md`、`docs/ATTACHMENT-FEATURES.md` 和 `docs/ATTACHMENT-GAP.md`。

## 十个模板的必填列

| 模板 | 必填列 |
| --- | --- |
| 银行日记账 | 业务单号、交易日期、对方名称、摘要、入账金额、出账金额、余额、分类 |
| 银行对账单 | 银行流水号、交易日期、对方名称、摘要、收入金额、支出金额、银行余额、业务单号 |
| 销售单 | 业务单号、销售日期、客户名称、到期日、含税金额、币种 |
| 采购单 | 业务单号、采购日期、供应商名称、到期日、含税金额、币种 |
| 付款单 | 付款单号、业务单号、付款日期、供应商名称、付款金额、币种 |
| 工资明细 | 工资月份、员工编号、员工姓名、部门、应发工资、社保基数、公积金基数、个税、其他扣款、发薪日、个税缴款日、社保公积金缴费日 |
| 费用报销单 | 报销单号、提交日期、员工编号、员工姓名、部门、费用日期、费用类别、费用说明、收款方、报销金额、税额、发票号码、真实性、发票合规、审批状态、审批完成日、付款日期、付款状态、预算科目、预算金额、账务处理状态 |
| 固定资产清单 | 资产编号、资产名称、资产类别、购置日期、原值、使用年限(月) |
| 发票台账 | 发票号码、发票类型、开票日期、销方名称、含税金额 |
| 产品成本 | 产品编号、核算月份、产品名称、产量、直接材料、直接人工、制造费用、标准成本（可空） |

费用报销审核规则：真实性、票据合规和审批完整性任一未通过，单据不会进入待付款队列；同一发票号码重复时需要人工核对。预算执行率按已审批金额除以预算金额计算，已审批未付款和已付款都占用预算，只有有付款日期的合规已审批单据进入现金预测。

银行对账以银行提供的对账单余额和实际流水为外部核对依据：银行已达账但账面未记录的项目先调增账面，账面已记录但银行尚未达账的项目进入银行端调节；差额和未达账项需要财务人员结合回单、付款审批或存款凭证完成核实。

工资核算公式：个人社保/公积金 = 对应基数 × 个人比例；单位社保/公积金 = 对应基数 × 单位比例；实发工资 = 应发工资 - 个人社保 - 个人公积金 - 个税 - 其他扣款；单位薪酬总成本 = 应发工资 + 单位社保 + 单位公积金。比例和基数上下限需要按参保城市与年度政策确认，不能把演示参数直接用于实际发薪。

模板按钮会优先下载真正的 `.xlsx` 文件，若浏览器未加载解析器则回退为 CSV。目录中同时放置了本地 SheetJS 解析器，浏览器可直接读取 `.xlsx`。

## 离线授权与续费

公开 Git 版本使用离线签名授权：用户首次打开后免费试用 7 天；到期后，用户通过订单号、客户名称或其他线下渠道联系授权方，授权方使用私有生成器生成新的签名授权码，用户在“授权与设置”中粘贴授权码即可续费。用户不需要提供设备 ID、登录账号或联网。

项目内只包含用于验签的公钥，私钥和 `generate-license.mjs` 只保留在授权方的卖家工具包中，不能提交到公开 Git 或销售项目包。授权码包含客户、版本、功能和到期日，续费时直接发一枚新码；项目通过 RSA-PSS 签名验证授权内容，没有在线 API。

本地网页的 7 天试用和授权属于软门槛：用户清除浏览器数据、修改本地源码或重置系统时间后可能绕过限制。若需要更强保护，应将项目封装为 Tauri/Electron 桌面版，把试用和验签放在原生启动器中；不能把纯 HTML/JavaScript 宣传为不可破解的加密程序。

## 单机边界

当前版本只支持一个财务主体、CNY 和 Asia/Shanghai。销售包使用本地启动器在 `127.0.0.1` 打开页面，不连接外部服务；旧的在线授权文件已从公开项目移除，离线销售包只包含本地启动器和签名验权。
